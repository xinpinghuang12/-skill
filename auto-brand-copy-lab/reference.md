# MONA Copy Lab Reference

品牌锁定小鹏 MONA；支持任意节日主题泛化。

## Compliance

| 不要写 | 可以写 |
|--------|--------|
| 自动驾驶 | 智能辅助驾驶 / 组合辅助驾驶 |
| 解放双手、零接管 | 保持专注，必要时接管 |
| 无依据低价承诺 | 以门店当期政策为准 |
| 贬低竞品 | 讲 MONA 场景利益 |

## Any festival → copy

1. 写出节日情绪词（必有）  
2. 挂上 1 个 MONA 利益（必有）  
3. CTA（默认证驾/到店）  
4. 再分渠道扩写  

| 节点类型 | 情绪词示例 | MONA 勾连 |
|----------|------------|-----------|
| 情感节 | 结缘、见证、双向 | 陪伴出行、故事感 |
| 她经济 | 犒赏、选择权 | 颜值、好停好开 |
| 长假 | 出发、充能 | 试驾、假期到店 |
| 团圆节 | 团圆、家 | 家庭出行场景 |
| 消费节 | 趁现在、做决定 | 权益口径（不写死） |
| 新品/到店 | 首发、尝鲜 | 可感知升级 |
| 车主节 | 自己人 | 归属与转介 |
| 其他 | Step 解码 | 年轻智能座驾 |

## Skeletons

朋友圈：`节日一句 + 体验利益 + 软邀约 + 政策免责`  
小红书：痛点/向往 → 3 细节 → 适合谁 → 温和 CTA → 标签  
口播：钩子 → 单点 → CTA  
话术：问场景 → 复述 → 30秒利益 → 邀试驾 → 留资  

## Bad → Good

- ❌ 任何节日都写「因 AI 结缘」（那是情人节专用锚点）  
- ✅ 中秋写团圆出行；国庆写假期试驾；双十一写决策加速（政策待确认）
