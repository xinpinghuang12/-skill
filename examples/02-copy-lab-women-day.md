# 示例：「把高光，开给自己」全渠道文案多版本包

> Skill：`auto-brand-copy-lab`  
> 可在 GitHub 直接阅读，无需下载 PDF

---

## Input（输入）

```text
用 auto-brand-copy-lab，
主题「把高光，开给自己」，品牌 MONA，
节点：女神节，目标到店试驾，
出全渠道多版本文案，价格不要写死。
```

---

## Output（输出预览）

### 策略一句话

面向年轻女性决策者与首购用户，用自我犒赏情绪 +「好看、好停、好开」利益，推动预约试驾。

### 卖点转译

| 产品点 | 用户利益 | 场景 |
|--------|----------|------|
| 高颜值 / 配色 | 开出门有自己的风格 | 通勤、周末出片 |
| 智能辅助驾驶 / 好停 | 日常更从容（保持专注） | 窄车位、城市道路 |
| 智能座舱 | 好玩好用少折腾 | 每天上下班 |

### 1) 海报 KV（推荐用 A）

| 版本 | 主标题 | 副标题 |
|------|--------|--------|
| **A 推荐** | 把高光，开给自己 | MONA 女神节体验，好看又聪明 |
| B | 今天的主角位，留给你 | 到店沉浸体验，预约试驾 |
| C | 漂亮，是认真生活的证据 | 第一台智能座驾，从体验开始 |

### 2) 门店朋友圈（推荐版）

> 周末与其只逛街，不如把「好看又聪明」坐进真实里。  
> 女神节到店体验进行中，我帮你留试驾位～  
> （礼遇以门店当期为准）

**置顶回复：** 回「试驾+时间」，发你路线与停车指引

### 3) 小红书（节选）

**标题**  
第一台车想要什么感觉？通勤不累 + 停车不慌 + 颜值在线

**正文要点**
- 场景：下班后给自己留一点仪式感  
- 细节：好看、好停、智能座舱好上手  
- CTA：评论城市 / 私信预约试驾  

**标签示例：** `#小鹏MONA` `#女神节` `#试驾体验` `#年轻第一台车` `#智能辅助驾驶`

### 4) 短视频口播（30s）

- **钩子：** 很多女生选车不是只看参数，是问：它能不能让我每天少烦一点？  
- **中段：** 好看是第一眼，好停和好开是每一天。  
- **CTA：** 想体验就私信我，帮你约到店试驾。

### 5) 门店话术（到店）

1. 开场：您更在意颜值、好开好停，还是智能好用？  
2. 讲解：按您的优先级，两分钟讲清场景利益。  
3. 收口：我们安排一次短途试驾，您真实感受后再决定。  
4. 留资：加企微，后续政策与档期我同步您（以门店当期为准）。

> **合规提醒：** 统一使用「智能辅助驾驶」；勿写自动驾驶 / 解放双手 / 零接管；勿写未确认价格。

### 6) AI 复用

替换节日词、车色、门店名、城市名，即可批量再生全渠道版本。
