# XPENG / MONA Festival Reference

品牌固定为小鹏 MONA。本文件支持**任意节日泛化**；小鹏实战案例只作锚点，不是唯一可做节点。

## Compliance

| 禁用/慎用 | 推荐 |
|-----------|------|
| 自动驾驶 | 智能辅助驾驶 / 组合辅助驾驶 |
| 高阶智驾（易误解） | 辅助驾驶体验 |
| 解放双手、脱眼、零接管 | 保持专注，必要时接管 |
| 无依据「最强/第一」 | 可体感场景利益 |

续航、优惠数字无确认来源不写死。

## Brand lock（MONA）

- 调性：年轻、潮酷、科技平权、高颜值、好用好玩
- 人群参考（公开口径）：偏 30 岁内；90/00 后为主；女性占比常报超四成
- 避免网约车感；强化「年轻人第一台智能座驾」
- 她经济：真实用车场景，不刻板粉红说教

## Any-festival decode（核心泛化逻辑）

对任意节点问 4 个问题：

1. **今天用户情绪是什么？**（团圆/宠爱/出发/决策/归属…）
2. **MONA 哪一点最自然接得住？**（颜值/好停好开/智能辅助驾驶体验/年轻态度/车主归属）
3. **主转化选哪个？**（传播 / 到店 / 试驾 / 留资 / 车主活跃）
4. **投入级别？**（A 重兵 / B 常规 / C 一张海报+话术）

主题 = 情绪词 + MONA 差异点 + CTA  
弱相关节日 → 轻关联（先情绪，后到店），禁止硬广贴节。

## Case anchors（实战锚点，勿当个人 KPI）

仅说明「小鹏做过哪些打法可复用结构」：

1. **情人节政企合作型**：仪式+巡游+媒体（情感公关）
2. **女神节她经济型**：场景种草+到店礼遇
3. **五一假期冲量型**：统一口径+试驾疏导
4. **520 车主+新品预热型**：归属感活动+开箱传播

新节日 = 借用上述**结构类型**，替换情绪与主题，不生搬旧口号。

## Materials / KPI / Retro

物料最小集：主视觉、展架、桌卡 FAQ、到店礼、口播提纲、门店通知  
审核：T-14 初稿 → T-10 终审 → T-7 到店 → 上线前 24h 检查  

KPI：曝光、互动、预约、到店、试驾、有效留资  
复盘五问：听懂？谁带来到店？卡点？可复用？下期只改一件事？

## Anti-patterns

1. 换了节日仍复读情人节/520 旧文案  
2. 节日与 MONA 无关联却强促销  
3. 只传播不承接门店  
4. 虚构数据、违规驾驶话术
